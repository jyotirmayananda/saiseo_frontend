# Deployment Guide: Netlify (Frontend) + Render (Backend)

This guide walks you through deploying your Next.js frontend to **Netlify** and your Express/MongoDB backend to **Render**, ensuring they connect securely and share cookie-based authentication.

---

## 1. Backend Deployment (Render)

Deploy your Node.js/Express service on **Render**:

1. **Create a New Web Service**:
   - Go to [dashboard.render.com](https://dashboard.render.com/) and click **New > Web Service**.
   - Connect your GitHub repository.
2. **Configure Service Settings**:
   - **Name**: `saiseo-backend` (or your preferred name)
   - **Root Directory**: `backend` (Ensure this is set so Render only builds the backend folder)
   - **Runtime**: `Node`
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
3. **Add Environment Variables**:
   Click **Advanced > Add Environment Variable** and add:

   | Key | Value | Notes |
   | :--- | :--- | :--- |
   | `NODE_ENV` | `production` | Enables secure HTTP-only cookies |
   | `MONGO_URI` | `mongodb+srv://...` | Your MongoDB Atlas connection string |
   | `JWT_SECRET` | `your-secure-random-string` | Must be identical to the one on Netlify |
   | `ADMIN_EMAIL` | `admin@saiseo.com` | Primary admin email |
   | `ADMIN_PASSWORD`| `your-admin-password` | Admin login password |

4. **Deploy**: Click **Create Web Service**. Once deployed, copy your service URL (e.g. `https://saiseo-backend.onrender.com`).

---

## 2. Frontend Deployment (Netlify)

Deploy your Next.js frontend to **Netlify**:

1. **Create a New Site**:
   - Go to [app.netlify.com](https://app.netlify.com/) and click **Add new site > Import from Git**.
   - Select your repository.
2. **Configure Build Settings**:
   - **Build Command**: `npm run build`
   - **Publish Directory**: `.next` (automatically detected by `@netlify/plugin-nextjs` in [netlify.toml](file:///Users/jyotimayanandasahu/project/saiseo/netlify.toml))
3. **Add Environment Variables**:
   Go to **Site configuration > Environment variables > Add variables** and add:

   | Key | Value | Notes |
   | :--- | :--- | :--- |
   | `BACKEND_URL` | `https://saiseo-backend.onrender.com` | Your backend URL from Render (without trailing slash) |
   | `JWT_SECRET` | `your-secure-random-string` | **Must match exactly** the JWT_SECRET on Render |

4. **Deploy**: Click **Deploy site**.

---

## 🔒 Security & Cookie Verification Note

Because the Next.js frontend proxies all `/api/*` requests directly to the Render backend, the browser sees all traffic coming from your Netlify domain. This means:
- No CORS (Cross-Origin Resource Sharing) configuration is needed.
- Cookies are treated as first-party cookies by browsers, preventing modern privacy restrictions (like Safari ITP) from blocking logins.
- Ensure the `JWT_SECRET` is **exactly the same** on both Netlify and Render so Next.js server-side middleware can verify the tokens generated by the Express backend.
